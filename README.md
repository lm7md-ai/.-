# نَبض · Tech Pulse

منصة عربية ثابتة لأخبار التقنية والذكاء الاصطناعي، ومستودعات البرمجيات مفتوحة المصدر، وأفكار تطوير واقعية. تعمل على **GitHub Pages** باستخدام **GitHub Actions** دون خادم دائم أو مفتاح API مدفوع.

## ما الذي تحتوي عليه؟

- تصميم داكن حديث، اتجاه عربي RTL، واجهة متجاوبة للجوال والكمبيوتر.
- أخبار عالمية وسعودية، Python، أبحاث ML/AI، فرص تقنية، وGitHub OSS.
- أربع فترات يومية (00–06، 06–12، 12–18، 18–24 بتوقيت السعودية).
- ترتيب تقديري للرواج أو ترتيب زمني، البحث، التصفية، الحفظ محليًا، وعرض التفاصيل والصور إن وفرتها المصادر.
- **لكل مشروع مفتوح المصدر أو فكرة معروضة: 10 تحسينات و10 أفكار مشاريع جديدة** من مكتبة مقترحات متخصصة حسب المجال. الأفكار مقترحات آلية قائمة على قوالب تحريرية، وليست بحثًا عميقًا مستقلاً في شيفرة كل مشروع.
- حفظ العناصر بالأرقام التعريفية الروابط لمنع تكرار نفس المقال عند عمليات الجمع اللاحقة.
- لا نختلق أخبارًا أو صورًا إذا فشلت المصادر؛ نحتفظ بآخر لقطة متاحة.

## النشر على GitHub Pages

1. أنشئ مستودعًا عامًا جديدًا باسم `nabdh-tech-pulse` في حساب GitHub الخاص بك (يمكن اختيار اسم آخر).
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع، مع الاحتفاظ بمجلد `.github` المخفي. لا ترفع الملف ZIP نفسه فقط.
3. انتقل إلى **Settings → Pages → Build and deployment → Source** واختر **GitHub Actions**.
4. من **Settings → Actions → General → Workflow permissions** اسمح بصلاحية **Read and write permissions** إن كان المستودع يحتاج ذلك كي يحفظ نتائج الأخبار. احتفظ بإعدادات الحماية الآمنة؛ لا تُضف Tokens أو أسرارًا إلى المستودع.
5. افتح **Actions → Refresh news and deploy Nabdh → Run workflow** وشغّل أول تحديث يدويًا. بعد اكتماله، تظهر وصلة الموقع داخل **Settings → Pages** أو سجل النشر.
6. يعمل التحديث تلقائيًا كل 3 ساعات (عند الدقيقة 17 من ساعات UTC القابلة للقسمة على 3؛ 03:17، 06:17، 09:17… بتوقيت السعودية). قد تتأخر جدولة GitHub Actions أحيانًا عن الموعد الدقيق، وقد تُعطّل الجدولة في المستودعات غير النشطة طبقًا لسياسة GitHub.

**عنوان الموقع المتوقع بعد نجاح النشر** (يتحدد بحسب اسم المستودع الفعلي): `https://YOUR-USERNAME.github.io/nabdh-tech-pulse/`. لا تعتمد العنوان بوصفه منشورًا حتى تنجح عملية النشر.

## المصادر والقيود

- GitHub Search API لجلب المستودعات العامة؛ رقم النجوم **تراكمي**، وليس عدد نجوم اليوم. تعرض الصور من README إذا اكتُشفت صور مناسبة؛ الصور غير مضمونة.
- Hacker News Algolia API لتفاعل المنشورات (نقاط + تعليقات).
- RSS من TechCrunch وThe Verge وarXiv، وخلاصات Google News للموضوعات السعودية وPython.
- بعض خلاصات Google News تضع رابط Google News الوسيط، وليس بالضرورة الرابط المباشر للموقع الناشر؛ يظهر مصدر الخبر مع الرابط المتاح في الخلاصة.
- ترتيب «الأكثر رواجًا» **مؤشر تقديري غير موحد بين المصادر** يجمع الشعبية المتاحة وحداثة التحديث. لا يدّعي معرفة عدد زيارات أو قراءات الخبر.
- الأوصاف من RSS وبيانات GitHub، وقد تكون أقصر من المقال الكامل. النصائح التفسيرية معرّفة بأنها تحليل أولي وليست حقيقة منسوبة إلى المصدر.
- موقع GitHub Pages ثابت؛ يحصل على النسخة الجديدة بعد نجاح Action والنشر، ويجري المتصفح فحصًا لملف البيانات كل 15 دقيقة. **ليس بثًا لحظيًا**، ولا يمكن ضمان الالتزام بالثانية المقررة للتحديث.
- حالة `seedData` في `site/data/feed.json` تعني أن البيانات المرفقة **تعريفية موثقة وليست تحديثًا مباشرًا**. يعيد المجمع إنشاء الملف من المصادر عند أول تشغيل ناجح.
- الحفظ محليًا في المتصفح (localStorage) فقط؛ لا يتزامن بين الأجهزة.
- لا تُنسخ الصور أو المقالات المطولة إلى المستودع؛ واجهة الأخبار تُظهر ملخصات وروابط المصادر فقط.

## التشغيل المحلي

```bash
python -m http.server 8000 --directory site
```

افتح `http://localhost:8000`. لتحديث البيانات من مصادر الإنترنت (إذا توفرت الشبكة):

```bash
python scripts/update_feed.py
```

لتشغيل الاختبارات دون اتصال:

```bash
python -m unittest discover -s tests -v
node --check site/app.js
node --check site/ideas.js
```

## الملفات الأساسية

| الملف | الدور |
|---|---|
| `site/index.html` | الواجهة | 
| `site/styles.css` | التصميم والتجاوب | 
| `site/app.js` | التصفية والمحفوظات والتفاصيل | 
| `site/ideas.js` | مقترحات 10+10 لكل مجال | 
| `site/data/feed.json` | الأخبار والمشاريع بدون تكرار |
| `site/data/seen.json` | بصمات المقالات السابقة لمنع إعادة إدخالها بعد أرشفتها | 
| `scripts/update_feed.py` | الجمع والتصفية والترتيب | 
| `.github/workflows/update-and-deploy.yml` | التحديث والنشر كل 3 ساعات |
