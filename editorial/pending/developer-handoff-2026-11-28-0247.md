## الحالة
- هذه الأفكار محفوظة للبحث فقط، وليست بطاقات عامة أو مشاريع منفذة.
- لا تضفها إلى Feed ولا تنشئ لها معرفات بديلة بالعنوان.
- لا تعدل الواجهة أو الشيفرة أو workflows ضمن هذا التسليم.

## العرض عند اعتماد مشروع مستقبلًا
1. اربط المشروع بمعرف Feed الأصلي وURL حرفيًا؛ إن لم يوجد تطابق، يبقى البحث في المكتبة الخاصة فقط.
2. اعرض المشكلة والنهج والتقنيات والخطوات والمقياس والصعوبة التقديرية والمخاطر والمصادر.
3. ميّز بوضوح بين الصعوبة المقدرة ونتائج الاختبار الفعلية.
4. اعرض `testStatus=not_run` ولا تنشئ `testEvidence` قبل تنفيذ اختبار حقيقي.
5. أظهر ما إذا كان الدليل مقالًا كاملًا أو README أو ملخصًا/بيانات وصفية.
6. احتفظ بروابط المصادر الأصلية وتاريخ المراجعة، ولا تعرض الأفكار البحثية غير المنشورة كبطاقات عامة.

## ترتيب الأولوية
1. حارس استرجاع آمن لعمليات الوكلاء ذات الكتابة.
2. مقياس تعاوني للفرق متعددة الوكلاء بميزانية متساوية.
3. مدقق علاقات للمشاهد ثلاثية ورباعية الأبعاد.
