# متطلبات عرض Octomind — بحث غير منشور

- وسم واضح: **بحث فقط / غير منشور كمشروع**.
- لا تنشئ بطاقة project أو رابط تفاصيل؛ رابط المستودع موجود في feed كخبر لا كبطاقة مشروع.
- اعرض الحالة والترخيص Apache-2.0 ومؤشرات GitHub مع وقت القياس، وافصل updatedAt المستقبلي كـtimestamp anomaly.
- اعرض overview وrequirements وquickStart وcostModel محلي/سحابي والبدائل.
- اعرض التحسينات والمشاريع المشتقة بكل حقول المشكلة والحل والتقنيات والخطوات والمقياس والصعوبة والمخاطر والمصادر.
- أظهر القيود الأمنية: guardrails ليست عزلًا كاملًا؛ sandbox موثق لـLinux/macOS؛ telemetry يحتاج مراجعة؛ ضبط النماذج الثلاثة مطلوب للمسار المحلي.
- اعرض benchmark المؤلفين بوصفه غير مستقل وعلى 25 مهمة فقط.
- لا تعرض زر تشغيل أو تثبيت أو شراء. لم يُختبر المشروع ولم تُستخدم خدمة مدفوعة.
- لا توجد أفكار دينية مناسبة موثقة لهذا المشروع.
