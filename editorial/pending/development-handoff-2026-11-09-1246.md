# متطلبات عرض محتوى المشاريع لمساعد التطوير — 9 نوفمبر 2026

هذه وثيقة متطلبات فقط؛ لا تتضمن تنفيذًا أو تعديلًا لشيفرة الموقع أو التصميم أو workflows.

## مصدر الحقيقة والهوية
1. اربط بطاقة المشروع بمعرف Feed الأصلي `id` ورابطه `url` حرفيًا.
2. اقرأ إثراء البطاقة من `site/data/editorial.json` عبر `items[id]`.
3. لا تنشئ معرفًا بديلًا من العنوان أو اسم المستودع.
4. لا تعرض عناصر مكتبة `editorial/library` البحثية كأنها بطاقات عامة؛ لا تصبح بطاقة عامة إلا بوجود تطابق Feed ID وURL وبطاقة مشروع فعلية.

## ترتيب التفاصيل
- الاسم/العنوان والرابط الرسمي للمستودع.
- `overview` أو `overviewShort`، ثم `requirements`.
- `quickStart` مع توضيح أنه مسار مقترح ولم يُنفذ إذا لم يوجد `testEvidence`.
- `localVsCloud` و`costs`، مع فصل تكلفة الترخيص عن تكلفة النموذج والاستضافة والبنية.
- الترخيص ومصدره، والبدائل مع روابطها.
- مؤشرات GitHub (stars/forks/openIssuesCount) مع `metricCapturedAt` أو `metricsMeasuredAt` ظاهرًا للمستخدم.

## التحسينات والمشاريع المشتقة
- اعرض `improvements` و`spinoffs` بترتيب المصفوفة الأصلي؛ لا تعِد ترتيبها حسب تقدير الواجهة.
- لكل اقتراح اعرض: `title`, `problem`, `approach`, `stack`, `steps`, `metric`, `difficulty`, `risks`, `sources`.
- اعرض `religious` فقط عند وجود أفكار ملائمة فعلًا؛ لا تنشئ قسمًا فارغًا ولا تضف حشوًا.
- لا تعرض شارة "مختبر/مجرّب" إلا إذا كانت `basis=tested` ووجد `testEvidence` واضح. غياب الدليل يعني "لم يُختبر".

## دقة البيانات
- وضّح أن `open_issues_count` من GitHub API قد يشمل Pull Requests، فلا تعرضه باعتباره عدد Issues فقط.
- اعرض وقت قياس المؤشرات؛ لا تصف timestamp مستقبليًا أو غير متسق بأنه دليل نشاط.
- احتفظ بروابط المصادر الأصلية، وميّز بين README والتوثيق والترخيص ومصادر البدائل.
- لا تحوّل خبرًا مرتبطًا بمستودع إلى بطاقة مشروع إذا كان `kind=news` وليس `kind=project`.

## متطلبات تجربة العرض
- دعم العربية وRTL، مع إبقاء أسماء الحزم والأوامر والروابط كما هي.
- استخدم أقسامًا قابلة للطي للتفاصيل الطويلة، مع إبقاء overview وrequirements وquickStart ظاهرة بوضوح.
- لا تخفِ limitations أو المخاطر أو تكاليف الخدمات الخارجية.
- لا تفترض وجود اختبار أو تشغيل أو دعم محلي لمجرد ذكره في README.

## نطاق هذه الدورة
- 100 بطاقة مشروع موجودة في Feed الحالي؛ إثراؤها موجود على فرع PR بعد مراجعة التراكم.
- المكتبة البحثية 65 مشروعًا، منها عناصر غير منشورة.
- لا توجد تغييرات تنفيذية مطلوبة ضمن هذه الدورة؛ هذه المتطلبات تسلّم لمساعد التطوير فقط.
